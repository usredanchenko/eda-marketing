# Brands

A brand is a folder `brands/<brand-id>/`. The engine discovers brands by scanning `brands/*/brand.json`; folders that start with `_` (such as `brands/_template/`) are ignored. Brands never mix: one package belongs to one brand, and no fact, token or phrase crosses from one brand to another.

## Example brand: `acme-focus`

Acme Focus is a fictional indie focus-timer app (`language: en`). Use it to try the pipeline, to read a complete brand kit and as a pattern for your own. It is not a real product; its facts exist only to exercise the fact statuses.

## Create a brand

```bash
npm run mos -- brand new <brand-id> --name "<Name>" --language en   # or ru
npm run mos -- brand validate <brand-id>
```

`brand new` copies `brands/_template/` and fills ids and names. Alternatively run the interview `/eda-marketing:marketing brand new`: it asks about the product, audience, positioning, voice and visual identity, then writes the brand kit, `brand.json`, `tokens.json` and `facts.yaml` with every fact you did not confirm marked `NEEDS_CONFIRMATION`.

Other brand commands: `brand list`, `brand show <id>`, `brand facts [id]` (regenerates `PRODUCT_FACTS.md`), `tokens` (regenerates HyperFrames CSS).

## Brand files

| File | Purpose |
|---|---|
| `BRAND.md` | What the product is; content strategy. |
| `AUDIENCE.md` | Segments. Hypotheses until data confirms them. |
| `POSITIONING.md` | How we talk about the product and what we never say. |
| `CONTENT_PILLARS.md` | Content pillars and formats. |
| `TONE_OF_VOICE.md` | The creator's voice, with real quotes when available. |
| `FORBIDDEN_CLAIMS.md` | Prohibitions and what needs confirmation. |
| `MOTION_LANGUAGE.md` | Visual and motion language. |
| `facts.yaml` → `PRODUCT_FACTS.md` | Checkable facts with statuses. The Markdown is generated by `mos brand facts`; do not edit it by hand. |
| `brand.json` | Machine-readable profile and brief defaults. |
| `tokens.json` | Design tokens for Remotion and HyperFrames. |

The seven Markdown docs plus `PRODUCT_FACTS.md` form the brand kit.

## `brand.json`

| Key | Contents |
|---|---|
| `id`, `names` | Working id, public name and its status, accepted spellings. |
| `language` | `en` or `ru`. Selects the language pack (see below). |
| `author` | Creator name and role. |
| `defaults` | `mode`, `template`, `formats`, `platforms`, `durationSec` `[min, max]`, `captionMode` (`replace` / `accumulate` / `highlight`), `fps`. |
| `speech` | `syllablesPerSec` for estimated timing; `calibrated` once measured with `mos captions calibrate`. |
| `captions.protectedPhrases` | Phrases a caption page must never split (product names, set expressions). |
| `claims` | `forbiddenPatterns` and `needsConfirmationPatterns` (regex) for scripts, on-screen text and copy. |
| `cta` | `editorial` (on-screen only) and `spoken` variants. |
| `hashtags` | `core` tags and `max` (≤5). |
| `ideaWeights` | Weights of the 9 idea criteria: relevance, novelty, audienceFit, visualPotential, emotionalPotential, storytellingPotential, productionComplexity, authenticity, productRelevance. |
| `research` | `themes`, `queries`, `communities`. |

## `tokens.json`

| Key | Contents |
|---|---|
| `colors`, `gradients` | Palette and linear/radial gradients. |
| `roles` | Semantic colors: `bg`, `surface`, `text`, `muted`, `accent`, `cardBg`, `cardInk`, `status.*`. Components use roles, not raw colors. |
| `styles` | `accentText` and `ctaText`: `solid` or `gradient`. |
| `fonts` | `sans`, `mono` and font `files` with weight, style, path and license. |
| `type` | Type scale (family, weight, size, line height, letter spacing, uppercase). |
| `radii`, `motion` | Corner radii; easing curves, enter frames, GSAP equivalents. |
| `captionStyles` | `replace`, `accumulate`, `highlight`: colors, weights, size, alignment, step indent, shadow. |

`mos video register` generates the Remotion registry and brand tokens; `mos tokens` generates `tokens.css` for HyperFrames. Shared fonts (Manrope, JetBrains Mono) live in `assets/` under the OFL. A brand may add its own fonts if their license allows embedding in video.

## Fact statuses (`facts.yaml`)

| Status | Use |
|---|---|
| `PUBLIC_CONFIRMED` | May be published, never stronger than `publicWording`. |
| `INTERNAL` | Planning only. Never on screen or in copy. |
| `NEEDS_CONFIRMATION` | Never published until the user confirms it. |
| `FORBIDDEN` | Never. |

Every product claim in a script, on screen or in copy must resolve to a fact. When a fact is missing, write `[CONFIRM: <what is missing>]` and ask; never invent it. `metric` and `progress` scenes require a `factId` with status `PUBLIC_CONFIRMED`. Do not import infrastructure details, keys, personal data, internal metrics, commercial terms or security findings into a brand folder.

## Language packs

`brand.json → language` selects `packages/core/src/lang/<en|ru>.ts` and `config/lang/<en|ru>/banned-phrases.yaml`.

| Concern | EN | RU |
|---|---|---|
| Caption grouping (never split) | articles, prepositions with their word, "to" + verb, "not", number + unit, names, `protectedPhrases` | proclitics and enclitics, «не», prepositions, number + unit, names, `protectedPhrases` |
| Typography | non-breaking glue for short words and units | non-breaking glue for short words, units, dashes |
| Estimated timing | English syllable counter | Russian vowel-based syllable counter |
| Content memory | English stopwords and stemming | Russian stopwords and stemming |
| ASR | faster-whisper language `en` | faster-whisper language `ru` |

Adding a language means adding a pack, a banned-phrases file and tests; brands then opt in through `language`.
