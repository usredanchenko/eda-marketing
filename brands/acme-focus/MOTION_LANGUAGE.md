# Acme Focus — motion language

## Character
Quiet and precise: short ease-outs, no bounce, generous holds so text can be read.

## Allowed motion elements
- Notification cards for "distractions" (honestly labeled as illustration).
- Message bubbles, timer callouts, title wipes in coral.

## Never
- Fake screens of features that do not exist, confetti, neon, color filters on footage.
