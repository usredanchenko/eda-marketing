# memory/ — content memory

What the brand has already published or planned, so new ideas and hooks do not repeat old ones.

- `memory/index.jsonl` — generated by `npm run mos -- memory rebuild` from the seed plus every package in `content/`. Do not edit by hand.
- `memory/seed.jsonl` — optional. Videos made before you started using this system, one JSON object per line (same fields as the index: `id`, `brand`, `source: "seed"`, `date`, `topic`, `template`, `hooks`, `hookTypes`, `cta`, `status`, `outcome`, `notes`).
- `memory/FAILURES.md` — lessons from things that did not work (process, footage, edits, publishing). Short entries, newest first.

Check a new topic against memory with `npm run mos -- memory check`.
